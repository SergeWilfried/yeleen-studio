# @studio/catalog

Source unique des modèles, de leurs capacités et de leurs prix en jetons.

- `@studio/catalog` : modèles image, vidéo, audio, `toJetons`, `imageCost`, `videoCost`, `voiceCost`, `priceLabel`, `durationOptions`.
- `@studio/catalog/recipes` : modèles de la galerie Cinéma (workflows fal : photos + quelques mots), prix = somme des plans.
- `@studio/catalog/chains` : chaînes de modèles et leur export en workflow fal (`workflowJson`).

JavaScript pur, sans dépendance. Pas d'icônes ni de libellés d'interface : ceux-ci sont dans `apps/web`.
